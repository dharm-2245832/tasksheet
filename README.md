# Habits Tracking MVP
This is a mobile-first, Next.js habit-tracking prototype built with Tailwind CSS, Recharts, and Prisma.

## Getting Started
1. Run `npm install`
2. Create `.env` file from `.env.example`
3. Generate Prisma client & DB: `npx prisma db push`
4. Run `npm run dev`

Open [http://localhost:3000](http://localhost:3000)

Log in with any email and the password `password123` for frictionless onboarding!
